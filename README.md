# Cryptocurrency Market Analysis & KPI Dashboard

## 📊 Project Overview

This project analyzes cryptocurrency market data from **March 16 and March 17, 2022** using **Python, Pandas, Excel, and Looker Studio**.

The project transforms raw cryptocurrency market data into an interactive dashboard that provides insights into:

- Market capitalization
- 24-hour trading volume
- Price performance
- Day-over-day price changes
- Top gainers and losers
- Cryptocurrency-level performance

The project demonstrates an end-to-end **Data Analytics workflow**, from data cleaning and transformation to KPI development, visualization, and business insights.

---

## 🎯 Project Objective

The main objective of this project is to analyze cryptocurrency market data and build an interactive dashboard that answers key analytical questions such as:

- What is the total cryptocurrency market capitalization?
- Which cryptocurrencies have the highest market capitalization?
- Which cryptocurrencies have the highest trading volume?
- How many cryptocurrencies gained or lost value?
- Which cryptocurrencies recorded the largest daily gains and losses?
- How does cryptocurrency performance vary across the dataset?
